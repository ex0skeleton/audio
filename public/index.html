Which export keeps exact quality?

Original copies the encoded source audio without re-encoding. Editing volume or converting to MP3/AAC/Opus changes the audio. WAV and FLAC preserve decoded samples, but cannot improve the source.

File support and limits

FFmpeg runs locally and loads on your first export. This workspace accepts one file at a time, up to 250 MB, to manage browser memory. DRM-protected media is unsupported. Extraction uses the first audio track.

Microphone and transcription

Microphone tools require permission. The recorder uses your browser's available recording codec. File transcription uses a local Whisper model and requires internet for the first model download. Accuracy varies; review results.
